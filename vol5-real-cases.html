01 · 선택

내 케이스를 고른다

막연하게 "뭔가 만들어야지"가 아니라, 완성 가능한 구체적인 것 하나를 고른다.
아래 세 영역 중 하나를 선택하고, 그 안에서 내 것을 정한다.

📱
앱 / 화면 제작
개발 케이스
iOS 앱의 특정 화면 하나를 AI와 함께 처음부터 끝까지 만든다.
"전체 앱"이 아니라 "화면 하나"로 범위를 좁힌다.
1어떤 화면을 만들 것인지 결정 (로그인, 목록, 상세, 설정 등)
2화면에 필요한 UI 요소 목록 작성
3데이터 구조 결정 (어떤 데이터를 표시하는가?)
4Vol.3 플로우대로 단계별 AI 요청
5각 단계 결과 검증 + 통합 테스트
⚙️
비서 / 자동화
생산성 케이스
반복적으로 하는 일 하나를 AI 또는 스크립트로 자동화한다.
회의 요약, 이메일 초안, 데이터 정리, 스케줄 관리 등.
1자동화하고 싶은 반복 작업 하나 선택
2현재 프로세스를 단계로 써본다
3어느 단계를 AI가 대체할 수 있는지 파악
4AI 프롬프트 또는 스크립트 작성
5실제 데이터로 테스트 → 개선
✍️
콘텐츠 생산
창작 케이스
블로그 포스트, 뉴스레터, 유튜브 스크립트, SNS 게시물 등
하나의 콘텐츠를 AI와 함께 처음부터 끝까지 완성한다.
1어떤 콘텐츠를, 누구를 위해 만드는지 결정
2핵심 메시지 3가지 정리
3AI에게 구조(목차/섹션) 먼저 요청
4섹션별로 작성 요청 → 내가 편집
5최종 검수 → 발행
