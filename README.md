# 바이브코딩 훈련소

**AI와 함께 코딩하는 법을 배우는 실전 워크북 시리즈**

> "일단 플로우를 만들어야 해요. 결국 코딩이라서 그걸 못하면 AI도 못 쓸 거에요." — 리이오

---

## 시리즈 구성

| Vol | 제목 | 대상 | 시간 |
|-----|------|------|------|
| Vol.0 | 나는 AI를 왜 쓰는가 | 입문 전 / 답답한 사람 | 20–30분 |
| Vol.1 | 말을 잘 해야 AI가 잘 한다 | 요청이 모호한 사람 | 30–40분 |
| Vol.2 | AI가 하는 말을 이해하는 법 | 응답을 못 알아먹는 사람 | 25–35분 |
| Vol.3 | 만들기 전에 흐름부터 그린다 | 플로우 없이 AI에 맡기는 사람 | 35–45분 |
| Vol.4 | 결국 코딩이다 | 코딩 0인 사람 | 40–50분 |
| Vol.5 | 케이스별 실전 | 목적은 있는데 시작 못 하는 사람 | 60분+ |

---

## 사용 방법

1. `index.html`을 열어 시리즈 전체를 확인한다
2. Vol.0부터 순서대로 진행한다
3. 각 실습 칸을 반드시 직접 채운다
4. 실전에서 막히면 해당 Vol로 돌아온다
